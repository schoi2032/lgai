# SNS 개인정보 지킴이

브라우저에서 바로 사용하기: **[SNS 개인정보 지킴이 열기](https://schoi2032.github.io/lgai/)**

설치나 명령어 없이 위 링크에서 사용할 수 있습니다. GitHub Pages가 `main`의 루트 `index.html`을 제공하며 앱은 `dist/`에서 실행됩니다.

게시물 각각은 평범해 보여도, 작은 단서들이 연결되면 신원·장소·일정이 추정될 수 있습니다. SNS 개인정보 지킴이는 사용자가 직접 고른 게시물의 단서를 함께 살펴보고, 필요한 부분만 줄이는 방법을 제안하는 청소년 캠프용 MVP입니다.

## 주요 기능

- 자동 예시 데이터 없이 시작하는 기존/새 게시물 입력
- 이미지(JPG/PNG/WEBP, 최대 8MB), 글, 선택 날짜 입력과 기존 게시물 삭제
- 신원·장소·일정·조직·관계 단서를 기반으로 한 게시물 간 연결 분석
- AI 추정 위험도(낮음/주의/높음), 분석 근거, 펼쳐 보는 설명, 최소 수정 제안
- 사진 위 영역을 직접 드래그해 가리는 로컬 편집과 글 수정 제안 적용
- 사진 픽셀을 한국어·영어 신경망 OCR로 읽고, 실제로 읽은 글자와 탐지 위치 표시
- 탐지한 민감한 글자 영역 자동 가리기 및 수정된 사진을 다시 OCR 분석
- 연결된 기존 게시물 일괄 삭제 및 마지막 수정·삭제 되돌리기 (현재 세션만)
- 수정 전/후 재점검 비교
- 브라우저 세션 안에서만 업로드 이미지를 처리하며, SNS 연동·자동 수집은 하지 않음

## 기술 스택

HTML, CSS, ES Modules, Tesseract.js 6 (WebAssembly 신경망 OCR), Node.js 내장 테스트, Playwright 브라우저 테스트를 사용했습니다. OCR 실행 파일과 한국어·영어 모델은 `dist/vendor/`에 포함하여 같은 웹사이트에서 제공합니다.

## 실행 방법

```bash
npm test
npm start
```

그 뒤 `http://localhost:4173`을 엽니다. 일반 사용자는 위 GitHub Pages 링크만 열면 됩니다. 개발용 브라우저 테스트는 `npm ci` 후 `node e2e/photo-flow.mjs`로 실행합니다 (macOS Chrome 기준).

## 실제 분석 방식

배포본은 **PhotoAnalyzer + Tesseract 신경망 OCR**를 기본 사용합니다. 사진 파일명은 완전히 무시하며 사진 픽셀만 인식합니다. 모델이 읽은 텍스트·좌표·인식 신뢰도를 UI에서 확인할 수 있습니다. 인식 신뢰도는 OCR의 값이며 개인정보 안전 확률이 아닙니다. 캡션 단서에는 가짜 신뢰도 숫자를 붙이지 않습니다.

OCR 이후 신원·소속·일정·주소·이메일·전화번호 등을 규칙으로 찾고 연결합니다. 자동 가리기는 인식된 텍스트의 좌표에 검은 사각형을 실제로 그립니다. 재검사는 수정된 픽셀을 다시 읽어 단서와 연결 개수의 감소 여부를 계산합니다. API 키나 서버 환경변수가 필요하지 않습니다. 첫 사진 분석은 약 30MB의 모델·실행 파일 다운로드가 필요하며, 이후에는 모델을 재사용합니다.

사진·글은 서버나 AI 공급자에게 전송하지 않습니다. CDN에 업로드하지도 않습니다. 언어 모델은 브라우저 캐시에 보관될 수 있으나 게시물은 메모리에만 유지되고 새로고침하면 사라집니다.

## 개발 모드와 제한 사항

`MockAnalyzer`는 단위 테스트를 위한 텍스트 분석기로만 남아 있으며 배포 UI에서는 사용하지 않습니다. `PhotoAnalyzer`는 `PhotoReader` 인터페이스를 받도록 분리되어 다른 사진 분석 모델로 교체할 수 있습니다.

- AI의 분석은 틀릴 수 있으며 위험도는 프로토타입용 참고 정보입니다.
- OCR은 사진 속 텍스트를 읽습니다. 로고·얼굴·장소의 시각적 의미를 이해하는 범용 멀티모달 모델은 아니며 흐린 사진·작은 글씨·손글씨는 놓칠 수 있습니다.
- 위험도와 글 수정 제안은 규칙 기반이며 생성형 AI의 판단이 아닙니다.
- 자동 가리기는 탐지된 줄 전체를 가릴 수 있습니다. 원본 보존과 확인을 위해 되돌리기를 제공합니다.
- 게시물 정리는 이 앱에 추가한 기존 게시물만 삭제합니다. SNS 게시물 원본은 삭제하지 않습니다.
- 실제 서비스에는 더 강력한 업로드 보안, 동의·보관 정책, 모델 결과 검증이 필요합니다.
- 현재 MVP는 어떤 SNS 계정에도 자동 접근하지 않습니다.
