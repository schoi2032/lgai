# AI 퍼즐가드 (PuzzleGuard)

게시물 각각은 평범해 보여도, 작은 단서들이 연결되면 신원·장소·일정이 추정될 수 있습니다. AI 퍼즐가드는 사용자가 직접 고른 게시물의 단서를 함께 살펴보고, 필요한 부분만 줄이는 방법을 제안하는 청소년 캠프용 MVP입니다.

## 주요 기능

- 자동 예시 데이터 없이 시작하는 기존/새 게시물 입력
- 이미지(JPG/PNG/WEBP, 최대 8MB), 글, 선택 날짜 입력과 기존 게시물 삭제
- 신원·장소·일정·조직·관계 단서를 기반으로 한 게시물 간 연결 분석
- AI 추정 위험도(낮음/주의/높음), 분석 근거, 펼쳐 보는 설명, 최소 수정 제안
- 사진 위 영역을 직접 드래그해 가리는 로컬 편집과 글 수정 제안 적용
- 수정 전/후 재점검 비교
- 브라우저 세션 안에서만 업로드 이미지를 처리하며, SNS 연동·자동 수집은 하지 않음

## 기술 스택

빌드 도구가 필요 없는 HTML, CSS, ES Modules와 Node.js 내장 테스트 러너를 사용했습니다.

## 실행 방법

```bash
npm test
npm start
```

그 뒤 `http://localhost:4173`을 엽니다. 별도의 패키지 설치는 필요 없습니다.

## 환경변수 및 실제 AI

현재 배포본은 API 키 없이 시연할 수 있는 `MockAnalyzer`를 기본 사용합니다. 실제 AI를 붙일 때는 브라우저에 키를 넣지 말고, 서버의 `POST /api/analyze`에서 `OPENAI_API_KEY` 등 환경변수를 읽어 멀티모달 모델을 호출하세요. 프런트엔드는 `window.PUZZLEGUARD_ANALYZER_URL`이 설정된 경우 `RemoteAnalyzer`를 통해 그 서버 경로를 호출하도록 분리되어 있습니다.

```env
OPENAI_API_KEY=... # 서버 환경에만 설정, dist/에는 절대 저장하지 않음
```

## 개발 모드와 제한 사항

Mock Analyzer는 사용자가 입력한 글과 **사진 파일명**의 키워드를 바탕으로 일관되게 단서를 시연합니다. 사진 속 글자를 실제로 읽는 OCR/멀티모달 분석은 서버 AI 연결을 붙인 뒤 사용할 수 있습니다.

- AI의 분석은 틀릴 수 있으며 위험도는 프로토타입용 참고 정보입니다.
- 실제 서비스에는 더 강력한 업로드 보안, 동의·보관 정책, 모델 결과 검증이 필요합니다.
- 현재 MVP는 어떤 SNS 계정에도 자동 접근하지 않습니다.
